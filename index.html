How to Import This CSV into New World Scheduler (Read Before Bulk Importing)
  1. Test 1 Territory First (Recommended): Filter to a single territory (e.g., Category R - Rural 3-R), click Resolve Lat/Lon (Filtered Rows) so each address gets exact map coordinates, click Download Filtered / Selected Territory CSV, then in NWS select that specific territory and click Addresses → Import Addresses → Territory Addresses from CSV file.
  2. For Bulk All-Territory Geocoding (5,000+ addresses): Use the companion geocode_nws_locations.py script, which uses the free official US Census Batch Geocoder to resolve all addresses & verify coordinates against your territory boundaries in seconds.
  3. Territory Naming & Matching: This CSV exports clean UTF-8 (no BOM) with exact NWS headers: Category, CategoryCode, TerritoryNumber, Suffix, Type, Status, Number, Street, ApartmentNumber, City, State, PostalCode, Name, Phone, Notes, Latitude, Longitude so your territory naming conventions (e.g., C-2-B, C-3-H) stay intact.
  4. Already have Do Not Calls pinned in Territory Helper? Set Do Not Calls (DNC) Handling above to Exclude DNCs before downloading so you don't create duplicate DNC entries.
  5. Always check the NWS Import Log after importing to confirm every address matched cleanly.
